# 有期 Youqi

记好日期，安心有期。

一个轻量的有效期记录工具，从家庭药箱开始，也支持厨房、日化以及自定义标签。纯 HTML、CSS 和 JavaScript，无需安装依赖，可直接部署到 GitHub Pages 或嵌入现有产品。

## 已实现

- 默认展示药品标签，切换查看全部、厨房、日化、其他及自定义标签。
- 一件物品可添加多个标签，支持新增、编辑、搜索、归档和恢复。
- 直接填写到期日，或用生产日期和保质期辅助推算，保存前核对包装。
- 即将到期、已过期、当前有效状态，以及标签内的统计。
- 提醒时间、提前天数、额外提醒节点和稍后提醒。
- 导出 `.ics` 日历提醒；通知样式预览。
- 本地保存、JSON 备份导出和合并导入。
- 独立的示例模式；首次点击“开始记录我的物品”后进入空白个人记录。
- 响应式布局，适配手机和桌面。

## 使用

打开 `index.html` 即可使用。也可启动任意静态文件服务器：

```sh
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

GitHub Pages：在仓库 Settings → Pages 中选择从 `main` 分支的根目录部署。

## 数据与提醒边界

记录只保存在当前浏览器的 localStorage 中，不会自动上传到 GitHub 或其他服务器；不同设备和浏览器之间不自动同步。更换域名、清理浏览器数据、使用隐私模式等可能导致记录不可用，请导出备份。

当前版本没有后台推送服务。提醒设置保存的是提醒计划；通知预览不会发送真实手机通知。可以导出日历文件并导入系统日历，实际提醒效果取决于日历应用、导入选项及其通知权限。更改记录后，需要重新导出并更新日历。

生产日期计算仅为录入辅助，最终有效期需按包装确认；不提供用药建议。开封后的使用期限需自行核对产品说明，本版尚未单独追踪。

## 文件

- `index.html`：页面结构
- `styles.css`：响应式样式
- `app.js`：记录、标签、备份和提醒逻辑
- `favicon.svg`：站点图标

本项目不包含第三方分析脚本、远程字体、外部 JavaScript 依赖或真实个人记录。
