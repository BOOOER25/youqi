# 有期 Youqi

轻量的有效期记录工具。默认主推家庭药箱，也支持厨房、日化和自定义标签。

在线体验：https://boooer25.github.io/youqi/

## 本版功能

- 暖黄、奶油白与手绘描边的界面，手机单列、桌面双列卡片；新增表单和详情采用同一套样式。
- 简单标题与新增入口，移除顶部介绍与底部功能区。
- 有效期概览、临期 / 过期状态、标签筛选、搜索、归档和恢复。
- 上传 JPG、PNG、WebP 后自动抠图，支持保留原图、重新处理和移除图片。
- 图片显示在物品列表和详情中，刷新后仍保留。
- 在详情页直接添加备注，按日期分组、最新在前，每条显示当地时间的时分；保留多条历史记录，文字支持换行。旧备注没有时间戳，显示为“原有备注 · 时间未记录”。
- 列表缩略图和详情图片支持点击放大，图片下方可返回详情或编辑物品。
- 可选唯一标识：自由字符串，保留前导零、空格和标点；无数字格式、长度或唯一性校验。它与系统内部记录 ID 分开。
- 直接录入到期日，或按生产日期与保质期辅助计算，保存前核对包装。
- JSON 备份包含文字记录、标识和图片，导入时合并记录。
- 首次打开默认展示带图片的模拟数据；旧版空白个人记录升级后也会展示一次示例。已有个人记录保留，之后主动切换到“我的记录”会记住选择，不反复切回示例。示例与个人记录独立，旧版备份兼容。
- 10 条内置示例均配有物品照片，其中 5 条使用原图、5 条使用透明抠图结果。进入示例时为旧示例备注补充固定的虚构日期与时分；保留已添加的备注与自选图片，个人记录不补造时间或替换图片。

**本版完全没有通知功能。** 不发送推送、不请求通知权限、不导出日历、不运行提醒计划。临期仅按距到期日 30 天以内在当前页面标记。

## 图片处理

沿用之前小组件项目的 `@imgly/background-removal` 1.7.0，使用量化模型 `isnet_quint8`，在浏览器 Worker 中运行。图片不会上传到远程抠图服务器。首次上传需要下载抠图模型与运行资源；资源由该库默认官方资源地址提供，网络或设备较慢时可直接使用原图。

单张上传最多 20 MB；读取后压缩至最长边 1200 像素，抠图结果裁去透明留白并缩放至最长边 640 像素。支持取消、失败重试和原图回退。不会在打开页面时预下载模型。

## 本地开发

已包含构建后的 `cutout-worker.js`，静态部署直接上传仓库文件即可，无需服务端。

```sh
npm ci
npm run build
python -m http.server 8080
```

访问 `http://localhost:8080`。Worker 应通过 HTTP(S) 访问，不支持直接用 `file://` 打开进行自动抠图。

GitHub Pages 从 `main` 分支根目录发布。

## 数据

文字记录存于 localStorage，图片存于 IndexedDB。所有个人数据只在当前浏览器内，不会自动同步到 GitHub 或其他设备。清除浏览器数据或更换访问域名可能导致记录不可用，请定期导出备份。

导出文件包含对应图片的原图与处理结果。导入最多支持 64 MB、2000 条记录，同内部 ID 的已有记录保持不变，用户自行填写的唯一标识不参与去重。

每件物品的 `notes` 保存备注数组（内部编号、正文、ISO 时间戳），单条最多 1000 字、每件最多 1000 条，随 JSON 一起导入导出。旧版 `note` 字段保留，编辑名称、图片等资料不会改写备注历史。新增物品保存后进入详情，可继续添加备注。

内置示例图片保存在站点中，支持放大、编辑、使用原图及备份。预制抠图结果直接显示，不需要查看示例时下载抠图模型。图片来源、作者、许可及加工说明见 `DEMO-ASSETS.md`。

旧版记录中的提醒字段在读取时忽略，后续保存时移除。本工具不提供用药指导；有效期以包装为准，开封后使用期限需核对产品说明。
